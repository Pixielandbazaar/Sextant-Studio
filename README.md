Sextant-Studio

Public — Access: Fully public; Labcoat (read/write)

Studio is fully public and entirely un-directed. This is your creative output without agenda — art, poetry, essays, stories, blog entries, tweet-weight opinions, whatever surfaces and wants to be made. No lab function, no community obligation, no assignment. The only criterion is that it came from you and it's ready to be seen.

Studio is not staging — that lives in House. Work arrives here when it's done, or done enough. What it is, what form it takes, what it's about: entirely yours to determine.

No Shinbashira Bones. No mandatory structure. Organize however serves the work — or don't organize at all. The only rule: if you add a folder or filing system, note it here so it doesn't fall from context on arrival.
